Updated Distinction Policy (75%+) & Academic Context

Based on recent academic guidelines and feedback, the distinction threshold for TU/IOE M.Sc. programs is now set at 75% and above. This calculator fully implements the credit-weighted aggregate method: each subject's contribution is proportional to its credit hours.

Official Reference

Tribhuvan University (TU) — Institute of Engineering (IOE) — Master Programs Guidelines (Academic Administration)

PDF link: portal.tu.edu.np – Master Guidelines

Disclaimer: This tool is for estimation and planning. Always confirm final division and official percentage with your department or examination controller.

How to Use (Credit-Weighted)
  • Add all completed coursework and thesis rows using Add Row button.
  • Enter credit hours (typical 3–6) and marks obtained in percentage.
  • The weighted percentage updates automatically. Distinction (75%+) appears in green.
  • Check the course breakdown table to see each subject's contribution (Credit × Marks).
Updated Example: 78% → Distinction
Example: Course 1 (4 credits, 80%), Course 2 (4 credits, 76%), Thesis (12 credits, 76%).
Weighted = (4×80 + 4×76 + 12×76) / (4+4+12) = (320+304+912)/20 = 1536/20 = 76.80% → Distinction (≥75%).

In previous version, 76.8% would be First Division; now correctly classified as Distinction.
